# ADR 0006：行为对比与确定性评测优先

- 状态：接受
- 日期：2026-07-28

## 背景

只比较最终文本无法解释 Agent 行为变化，单一模型裁判也无法稳定区分测量事实与主观判断。

## 决策

1. Run Compare 按 `Span kind + name + 同名出现序号` 对齐执行路径。
2. 对齐结果区分 `unchanged`、`changed`、`added`、`removed`。
3. 比较同时覆盖配置、运行状态、错误、工具调用、重复调用、耗时和已报告 Token。
4. Compare 只生成事实摘要，不在指标冲突时声明唯一胜者。
5. Eval Report 分为：
   - 测量事实；
   - 带版本的确定性规则评分；
   - 证据 Span；
   - 数据缺失与方法限制。
6. Provider 未返回 Token 时保持字段缺失，不估算或伪造。
7. v1 默认评测器为 `agentscope-deterministic-v1`；未来模型裁判必须作为独立、带版本的附加结果。

## 后果

- Parent/Child Fork 完成后可以自动生成行为差异。
- 每个规则评分可回到对应 Span，报告可导出为 Markdown 或 JSON。
- 同名步骤大量重排时，对齐仍可能不完美；后续可引入调用签名和可配置匹配器，但不改变当前输出结构。
